纸间 · 论文译读

使用方式
1. 双击“纸间论文翻译器.exe”。窗口底部始终保留开始翻译按钮，内容可用滚轮滚动。
2. 拖入一份 PDF（或点击浏览文件）；填写支持 OpenAI 接口的服务地址、模型和 API Key。支持中文和带空格的文件路径。
3. 选择译稿类型和可选页码，点击“开始翻译”。
4. 生成的 PDF 默认保存在 Windows 桌面，也可以更改保存目录。选择新文献不会重置已选目录。

首次翻译可能需要网络下载 BabelDOC 使用的版面识别模型与中文字库；模型会缓存到当前 Windows 用户的缓存目录。调用翻译服务需要网络和有效的 API Key。

服务地址、模型和 API Key 会自动保存，下次打开自动填入。密钥通过 Windows DPAPI 加密，仅当前 Windows 账户可以解密。设置位于 %APPDATA%\ZhijianTranslator\settings.json。点击“清除密钥”可删除保存的 Key。分享程序文件夹不会携带你的个人设置。

请在此文件夹内运行 EXE，不要单独移动 EXE。移动或分发时请保留整个“纸间论文翻译器”文件夹。

如出现问题，请确认 Windows 用户账户有权写入模型缓存目录和 PDF 输出目录，并确认 API 地址、模型名称和 Key 有效。
